# Journal

Mission order rationale:
- Tier 1 builds orientation and trace confidence.
- Tier 2 builds system reasoning and PR/debug skill.
- Tier 3 builds ownership and risk anticipation.

Code paths selected:
- Minimal bootstrap paths for quick wins.
- One complete metadata-driven feature (view sort) for realistic complexity.

Tier skill progression:
- Junior: read and explain concrete files.
- Mid-level: connect flows and evaluate tradeoffs.
- Senior: critique architecture, risk, and change strategy.

What seniors do differently at checkpoints:
- They test assumptions against line-level evidence.
- They identify invariants (guards, soft deletes, shared enums) before editing.
- They map blast radius before changing provider/middleware order.
