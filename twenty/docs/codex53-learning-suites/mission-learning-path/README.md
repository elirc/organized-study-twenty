# Mission Learning Path (Codex 5.3 Fresh Pass)

This suite is a training campaign, not passive documentation.

## How to use
1. Run missions in order.
2. Perform each checkpoint actively.
3. Use the self-grading rubric immediately after answering.
4. Do not skip to higher-tier missions before you can explain the previous one out loud.

## Pacing
- Junior tier: 1-2 sessions
- Mid-level tier: 2-3 sessions
- Senior tier: 2 sessions
