# User Story Build Path (Codex 5.3 Fresh Pass)

This suite gives you 10 progressive, domain-realistic tickets to build inside Twenty.

## How to use
1. Complete stories in order.
2. For each story, create a branch and write a short implementation journal.
3. Validate against acceptance criteria before asking for review.

## Difficulty progression
- Stories 1-3: Easy
- Stories 4-5: Medium-Easy
- Stories 6-7: Medium
- Stories 8-9: Hard
- Story 10: Expert

## Definition of done
- Acceptance criteria all pass.
- No lint/type regressions in touched scope.
- Change includes at least one negative-path test or manual verification note.

## Getting unstuck with an AI assistant
Use this prompt:

"I'm working on Story X. I'm stuck on Y. Here is what I've tried: Z. Don't give me the solution. Ask me questions that help me figure it out and point me to relevant files/functions in this repo."
