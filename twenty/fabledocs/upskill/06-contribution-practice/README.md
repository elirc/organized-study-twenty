# 06 — Contribution Practice

Reading builds maps; contributing builds judgment. This module is a ladder of realistic work, all designed to be **small-blast-radius, pattern-following, testable** — the three properties maintainers accept.

Reality check before any PR: Twenty is an active open-source project — check `CONTRIBUTING`/issue tracker upstream before investing; these tickets are formulated as *training exercises against this clone* first, upstream candidates second. Every ticket includes an **Interview story potential** line — completing even three tickets gives you concrete STAR material ([08-interview-prep/06](../08-interview-prep/06-behavioral-star-stories.md)).

For every contribution answer the maintainer's five questions: why is it useful, why is the blast radius small, what existing pattern does it follow, how is it tested, and what would make them reject it.
