# 04 — Code Reading Gym

Reading code is a trainable skill with reps, like a sport. Each drill here uses **real excerpts** from this repo (or clearly-labeled fakes for contrast) and ends with a self-grading rubric.

| File | Reps |
| --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | 8 excerpts to annotate: inputs, outputs, invariants, side effects, failure modes |
| [02-trace-tables.md](02-trace-tables.md) | 4 value-by-value traces across layers |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | 8 bad-vs-better pairs mapped to real repo patterns |
| [04-review-katas.md](04-review-katas.md) | 8 fake PRs to review with graded findings |

Method for every drill: read once fast (shape), read once slow (data flow), write your answer *before* checking, grade honestly. The writing step is not optional — unwritten answers feel more correct than they are.
